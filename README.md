# BAND UP

Мобильное веб-приложение для тренировок с длинными резиновыми петлями.

## Возможности

- каталог упражнений с резиной и GIF-анимациями;
- поиск и фильтрация по части тела;
- готовые тренировочные программы;
- интервальный таймер;
- история тренировок в браузере;
- PWA-режим и кэширование просмотренных упражнений.

Данные упражнений загружаются из открытого проекта [`hasaneyldrm/exercises-dataset`](https://github.com/hasaneyldrm/exercises-dataset) и фильтруются по `equipment = "band"`.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер или опубликуйте репозиторий через GitHub Pages.

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Стек

HTML, CSS, JavaScript, LocalStorage, Service Worker.
